# Portfolio Martini MKai

## Tester en local
Ouvre le dossier et lance un petit serveur : `python3 -m http.server 8000` puis va sur http://localhost:8000
(ou double-clique sur index.html).

## À personnaliser (dans index.html)
- Email : remplace `contact@exemple.com`
- Réseaux : remplace les `href="#"` de GitHub, LinkedIn, WhatsApp (ex. https://wa.me/229XXXXXXXX)
- Stage : renseigne les dates et le nom de l'administration dans la section « Parcours »

## Publier gratuitement avec GitHub Pages
1. Crée un compte sur github.com, puis un dépôt public nommé `martini-mkai`.
2. Envoie tous les fichiers de ce dossier (Add file > Upload files).
3. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
4. Ton site sera sur https://TON-PSEUDO.github.io/martini-mkai/
